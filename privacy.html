Jaco Backup Pilot

Privacy policy

Jaco Backup Pilot is a private desktop backup utility for Google accounts controlled by its owner.

Information accessed and its purpose

With the account owner's consent, the tool uses Google Drive read-only access to retrieve account identity, file names, folder relationships, file identifiers, dates, sizes and available checksums. It downloads selected file contents and exports supported Google documents. It uses this information to create backups, keep an index, check integrity and test recovery.

Storage and access

Downloaded files, exports, indexes and run records are stored in the owner's selected local backup storage. The owner may also copy them to an external backup drive. Account data is kept in separate backup folders. This website does not receive or store those backups.

Connection credentials are stored in an encrypted local configuration. The owner may keep a separately encrypted recovery copy. Access to local backup files depends on the security and permissions of the owner's devices; this policy does not claim that every downloaded file is encrypted.

Sharing and use limits

The backup process does not sell Google user data, use it for advertising, or send file contents to services that train general-purpose AI models. It uses Google user data for the owner's backup, indexing, integrity checks and recovery. The owner's separate actions with a downloaded file are outside this tool's automated backup process.

Jaco Backup Pilot's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Local backups are retained until the owner deliberately removes them. Deleting a file from Google Drive does not automatically delete its backup. The owner can revoke the application's access through their Google Account's third-party connections controls. Revoking access stops future access but does not remove copies already downloaded.

This information website

These pages contain no sign-in form, advertising or analytics scripts. The hosting provider, GitHub Pages, logs visitor IP addresses for security purposes under the GitHub Privacy Statement.

Contact and changes

For questions about this utility or its stored data, use the owner contact address displayed on the Google consent screen. This policy will be updated if the tool's data practices change.

Use of this private tool

The utility is for accounts controlled by its owner, with consent granted by that account owner. It is not offered as a public service. Operation depends on the owner's computer, internet connection and continued Google authorization. The owner chooses what to back up and checks that recovery works before relying on a backup or removing an original.
