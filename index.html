Private backup utility

Jaco Backup Pilot

A desktop tool that copies selected Google Drive files to the owner's local backup storage.

What it does

The tool connects to Google accounts controlled by its owner, using consent granted separately for each account. It reads file information, downloads selected files and exports supported Google documents for local backup and recovery.

Read-only access

The Google Drive connection requests drive.readonly. This allows it to list and download files. It does not give the tool permission to upload, modify or delete files in Google Drive.

Who uses it

This utility is operated privately by its owner. It is not a public backup service, and this website does not provide sign-in or access to any backup.

For support, use the owner contact address shown on the Google consent screen.
